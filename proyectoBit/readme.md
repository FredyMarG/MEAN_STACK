# ⏱️ Procrastination Nightmare (`proyectoBit`)

Suite web de productividad y organización desarrollada con **HTML5, CSS3, Bootstrap 5 y JavaScript ES6+** con persistencia local (`localStorage`).

## 🧩 Módulos incluidos

- [`index.html`](./index.html) & [`pomodoro.html`](./pomodoro.html) — Temporizador Pomodoro (Trabajo 25m / Descanso 5m) con alarma Web Audio.
- [`to-do-list.html`](./to-do-list.html) — Lista de tareas rápidas con estado completado y persistencia local.
- [`calendario.html`](./calendario.html) — Calendario mensual con creación de eventos, filtrado por categoría y subtareas.
- [`habitos.html`](./habitos.html) — Tracker semanal de hábitos con porcentaje de cumplimiento en tiempo real.
- [`roadMapTareas.html`](./roadMapTareas.html) — Tablero roadmap con POO (`taskData`), ordenamiento por fecha/texto/estado y cambio de estado.
- [`landing-full-bootstrap/index.html`](./landing-full-bootstrap/index.html) — Landing page promocional responsiva.
