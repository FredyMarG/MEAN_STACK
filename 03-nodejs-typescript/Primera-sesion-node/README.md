# 🟢 Primera Sesión de Node.js (`hello-world.js`)

Módulo introductorio del curso **MEAN Stack** enfocado en lógica de programación, bucles y algoritmos ejecutados directamente en **Node.js**.

## 📚 Ejercicios incluidos
1. **`evaluarSigno(valor)`**: validación numérica con `Number.isFinite` y clasificación positivo/negativo/cero.
2. **`evaluarParidad(valor)`**: uso del operador módulo (`%`) y comparación estricta (`===`).
3. **`multiplosXD(valor)`**: variante FizzBuzz (`X`, `D`, `XD`).
4. **`dibujarCuadrado(lado)`**: bucles `for` anidados para dibujar figuras en consola.
5. **`tablaDelCinco()`**: generación de tabla de multiplicar con *template literals*.
6. **`relojDigital(mostrarMuestra)`**: simulación de 24 horas (`00:00` a `23:59`) con `padStart`.
7. **`serieCien()`**: construcción limpia de secuencias con `.join(",")`.
8. **`primosHasta(limite)`**: cálculo de números primos optimizado en complejidad $O(n\sqrt{n})$.

## ▶️ Comandos disponibles
```bash
# Ejecutar en modo desarrollo (recarga automática al guardar cambios)
npm run dev

# Ejecutar una sola vez en consola
npm start

# Correr pruebas automatizadas
npm test
```
