# 🔷 Fundamentos de TypeScript (`TypeScript/`)

Módulo introductorio del curso **MEAN Stack** para dominar el tipado estático antes de trabajar con **Express + TypeScript (`ts_api`)** y **Angular**.

## 📚 Conceptos cubiertos en [`script.ts`](./script.ts)
1. **Tipos primitivos:** `string`, `number`, `boolean`.
2. **Arreglos y Tuplas:** `string[]` y `[string, number]`.
3. **Union Types:** `type RolDesarrollador = "frontend" | "backend" | "fullstack"`.
4. **Interfaces:** propiedades obligatorias, opcionales (`?`) y `readonly`.
5. **Funciones tipadas y Genéricos (`<T>`):** `crearPerfil()` y `envolverRespuesta<T>()`.
6. **Clases con encapsulamiento:** `public`, `private`, `readonly` en `CursoModulo`.

## ▶️ Comandos
```bash
# Ejecutar en consola con recarga automática
npm run dev

# Ejecutar una vez
npm start

# Correr pruebas unitarias
npm test
```
*(También puedes abrir [`index.html`](./index.html) desde el Hub para explorar los conceptos interactivamente).*
