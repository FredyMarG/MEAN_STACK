# 🚀 MEAN Stack Lab — Centro de Prácticas y Proyectos

Repositorio educativo del curso **Full-Stack MEAN Stack** (**MongoDB • Express.js • Angular • Node.js**).  
Abre [`index.html`](./index.html) en tu navegador para explorar todos los módulos, filtrar por tecnología y ejecutar las prácticas frontend en vivo.

## 🧱 Estructura del Curso

1. **🌟 Proyectos Integradores Full-Stack**
   - [`Turismo_MEAN/`](./Turismo_MEAN/README.md): Plataforma de Turismo (`TurismoBack` Express + MongoDB/JSON en puerto `4000` y `TurismoFront` Angular 16 con respaldo offline).
   - [`proyectoBit/`](./proyectoBit/readme.md): Suite web *Procrastination Nightmare* (Pomodoro, To-Do, Calendario, Hábitos y Roadmap POO).
   - [`procrastination-nightmare/`](./procrastination-nightmare/package.json): Versión SPA en Angular 16 (`npm run dev`).

2. **⚙️ Backend Node.js, Express, TypeScript & MongoDB**
   - [`BitShop_API/`](./BitShop_API/README.md): API REST Bit-Shop con JWT, hashing `scrypt`, RBAC, interfaz Login-first en `/` y respaldo local JSON automático (`npm run dev`).
   - [`ts_api/`](./ts_api/README.md): API modular en TypeScript estricto con interfaz Login-first en `/` (`npm run dev`).
   - [`Mongo/`](./Mongo/mongodb.js): Práctica CRUD `DBZ-V2` + simulador y Playground Web [`run-mongo-demo.js`](./Mongo/run-mongo-demo.js) (`npm run dev`).
   - [`Primera-sesion-node/`](./Primera-sesion-node/hello-world.js), [`TypeScript/`](./TypeScript/script.ts) y [`simpsons-db/`](./simpsons-db/package.json) (`npm run dev`).

3. **🅰️ Aplicaciones Angular**
   - [`Ejercicio_Angular/`](./Ejercicio_Angular/src/app/app.module.ts), [`proyectos-angular/`](./proyectos-angular/src/app/app.module.ts) y [`angular-input-output/`](./angular-input-output/src/app/app.module.ts) (`npm run dev` en cualquiera de ellos).

4. **⚡ JavaScript ES6+, DOM, APIs & Maquetación**
   - [`ejercicios-logica/`](./ejercicios-logica/index.html), [`repaso-js/`](./repaso-js/), [`rickandmorty_api/`](./rickandmorty_api/index.html), [`fetch_api/`](./fetch_api/index.html), [`Formulario/`](./Formulario/index.html), [`Tienda_Online/`](./Tienda_Online/index.html), [`Proyecto_Guiado/`](./Proyecto_Guiado/ecommerce.html), entre otros.
