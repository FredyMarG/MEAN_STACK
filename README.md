# 🚀 MEAN Stack Lab — Centro de Prácticas y Proyectos

Repositorio educativo del curso **Full-Stack MEAN Stack** (**MongoDB • Express.js • Angular • Node.js**), organizado de forma modular del `01` al `06`.  
Abre [`index.html`](./index.html) en tu navegador para explorar todos los módulos, filtrar por tecnología y ejecutar las prácticas frontend en vivo.

## 🧱 Estructura del Curso

1. **[`01-html-css/`](./01-html-css/)** — Maquetación HTML5, CSS3, Flexbox, Media Queries y Clones UI
   - `git-day-0/`, `Html-Basic/`, `Html-Css-Basic/`, `html5_exercise/`, `Media_querys/`, `Instagram/`, `Login/`, `Microsoft_Login/`, `Snapchat/`, `Spotify/`, `Proyecto_Guiado/`

2. **[`02-javascript/`](./02-javascript/)** — Lógica, DOM, Web Storage, Algoritmos y Consumo de APIs
   - `ejercicios-logica/`, `Formulario/`, `fetch_api/`, `hackathon/`, `JS-BIT-programing/`, `Local_Storage/`, `my-page-console/`, `Navbar-todolist/`, `repaso-js/`, `rickandmorty_api/`, `Tienda_Online/`

3. **[`03-nodejs-typescript/`](./03-nodejs-typescript/)** — Fundamentos de Node.js, TypeScript y NoSQL
   - [`Primera-sesion-node/`](./03-nodejs-typescript/Primera-sesion-node/README.md), [`TypeScript/`](./03-nodejs-typescript/TypeScript/README.md), [`Mongo/`](./03-nodejs-typescript/Mongo/run-mongo-demo.js), [`simpsons-db/`](./03-nodejs-typescript/simpsons-db/package.json)

4. **[`04-backend-apis/`](./04-backend-apis/)** — APIs RESTful con Express, TypeScript y JWT
   - [`BitShop_API/`](./04-backend-apis/BitShop_API/README.md) (puerto `5000`, `npm run dev`)
   - [`ts_api/`](./04-backend-apis/ts_api/README.md) (puerto `3000`/`3001`, `npm run dev`)

5. **[`05-angular/`](./05-angular/)** — Aplicaciones SPA en Angular 16
   - `angular-input-output/`, `Ejercicio_Angular/`, `proyectos-angular/` (`npm run dev` en cualquiera)

6. **[`06-proyectos-fullstack/`](./06-proyectos-fullstack/)** — Proyectos Integradores Full-Stack
   - [`Turismo_MEAN/`](./06-proyectos-fullstack/Turismo_MEAN/README.md) (`TurismoBack` + `TurismoFront`)
   - [`proyectoBit/`](./06-proyectos-fullstack/proyectoBit/readme.md) (Suite *Procrastination Nightmare* Web + Landing)
   - [`procrastination-nightmare/`](./06-proyectos-fullstack/procrastination-nightmare/package.json) (SPA Angular)
