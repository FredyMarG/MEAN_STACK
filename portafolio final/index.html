🏗️ Pilares Técnicos del Ecosistema MEAN

1. Frontend & Arquitectura SPA

Desarrollo de interfaces responsivas con HTML5 semántico, CSS3 Flexbox, Media Queries y Bootstrap 5, junto con aplicaciones Single Page Application (SPA) en Angular 15 con enrutamiento modular, componentes reutilizables, formularios reactivos e integración de librerías como FullCalendar.

2. JavaScript ES6+, DOM & Consumo de APIs

Implementación de lógica algorítmica, programación orientada a objetos (POO), manipulación dinámica del DOM, persistencia local con Web Storage API (`localStorage`) y consumo asíncrono de APIs REST mediante `fetch`, promesas y `async/await`.

3. Backend Node.js, TypeScript & MongoDB

Construcción de servidores RESTful con Express.js (tanto en JavaScript como en TypeScript con patrón de barriles), protección de rutas mediante JSON Web Tokens (JWT), control de acceso por roles y modelado de datos NoSQL en MongoDB y Mongoose.
