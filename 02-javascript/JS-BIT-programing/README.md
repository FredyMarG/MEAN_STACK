# 🔢 Buscador de Números Primos (`JS-BIT-programing/`)

Práctica de algoritmia en JavaScript enfocada en verificación de primalidad en complejidad $O(\sqrt{n})$.

## ✨ Funcionalidades
- **Detección de primalidad $O(\sqrt{n})$:** evalúa solo divisores impares hasta $\sqrt{n}$ y muestra el primer divisor exacto cuando el número es compuesto.
- **Próximos 5 primos:** calcula los siguientes 5 números primos a partir de $n$ (Postulado de Bertrand).
- **Métricas en vivo:** muestra iteraciones realizadas, tiempo de cálculo en milisegundos y un historial clicable de números recientes.
- **Modo clásico:** conserva el botón `Prompt` para probar `window.prompt()` y `alert()`.

## ▶️ Cómo probarlo
Abre [`index.html`](./index.html) en tu navegador o desde la **Vista Previa** del Hub principal.
