# 📋 Formulario Dinámico de Registro de Aspirantes (`Formulario/`)

Práctica de validación de formularios en JavaScript, manipulación del DOM segura contra XSS y persistencia en `localStorage`.

## ✨ Funcionalidades
- **Validación completa:** nombre, apellido, correo válido, aspiración salarial (`>= 0`), género y cargo.
- **Comportamiento dinámico:**
  - Al seleccionar **Otros**, habilita un campo de texto adicional.
  - Botón **azul** (`.btn-primary`) para *Hombre* y **rosado** (`.btn-pink`) para *Mujer*.
- **Gestión de datos:** búsqueda en tiempo real, eliminación individual, limpieza total, visor JSON en vivo y exportación a `aspirantes.json`.

## ▶️ Cómo probarlo
Abre [`index.html`](./index.html) en tu navegador o desde la **Vista Previa** del Hub principal.
