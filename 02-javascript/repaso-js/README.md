# ⚡ Repaso de Algoritmos en JavaScript (`repaso-js/`)

Módulo de práctica de algoritmos clásicos en Node.js:

1. **Cifrado ROT13 ([`for.js`](./for.js)):** rotación circular de +13 posiciones sobre códigos ASCII (`65–90` mayúsculas, `97–122` minúsculas) usando `% 26`.
2. **Bubble Sort Optimizado ([`repasojs.js`](./repasojs.js)):** ordenamiento inmutable con corte temprano (`swapped`) y saludo parametrizado.

## ▶️ Comandos
```bash
# Modo desarrollo con recarga automática
npm run dev

# Ejecutar ambos algoritmos en consola
npm start

# Ejecutar pruebas automatizadas
npm test
```
