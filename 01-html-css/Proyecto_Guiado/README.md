# 🛍️ Proyecto Guiado — E-Commerce Bootstrap 5 Grid (`Proyecto_Guiado/`)

Práctica de maquetación responsiva con **Bootstrap 5 Grid** (`row g-4` + `col-md-4`) y carrito de compras interactivo persistido en `localStorage`.

## ✨ Funcionalidades
- **Catálogo en grilla de 3 columnas** con imágenes de altura uniforme (`200px`, `object-fit: cover`).
- **Carrito persistente:** agrega productos, ajusta cantidades (`+` / `-`), calcula el total en COP dentro de `#cartModal` y confirma pedidos.
- **Vista complementaria:** incluye [`index.html`](./index.html) con tarjeta de perfil y navegación directa al catálogo [`ecommerce.html`](./ecommerce.html).
