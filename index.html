Guía Rápida de Ejecución Local

1. Backends Node / Express / Mongo

BitShop_API (puerto 5000, panel Login-first en /) y TurismoBack (puerto 4000) se ejecutan con nodemon y respaldo JSON local.

cd 04-backend-apis/BitShop_API && npm run dev cd 06-proyectos-fullstack/Turismo_MEAN/TurismoBack && npm run dev
2. API TypeScript & Scripts Node

ts_api se ejecuta con recarga automática vía nodemon + ts-node (panel Login-first en /) o compilado con npm run build.

cd 04-backend-apis/ts_api && npm run dev
3. Aplicaciones Angular

TurismoFront se conecta al backend en el puerto 4000 (con respaldo offline en localStorage).

cd 06-proyectos-fullstack/Turismo_MEAN/TurismoFront && npm run dev
